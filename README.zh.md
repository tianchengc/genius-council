## 💡 为什么需要 Genius Council？

绝大多数 AI 智能体都沦为了“被动生成长篇废话的打字机”：你给一个指令，它吐出 5,000 字毫无重点的文本，你读不进去，认知也没有任何实质提升。

**Genius Council 彻底打破这种低效死循环。** 它将你的 AI 转化为一个**高烈度的多导师商业决策作战室**：
1. **9 大东西方顶级思维透镜**：不再有千篇一律的 AI 套话，每位导师以真实人格与哲学切入。
2. **在写代码前击碎幼稚假设**：红蓝对抗演练，把所有导致破产的漏洞在沙盘阶段杀光。
3. **寻找非共识的结构性垄断**：跳出红海，发现传统竞争对手视而不见的套利空间。
4. **交付交互式 HTML5 作战室**：内置**双播客/语音高管简报、实时产品交互原型、动态 \$10k/月 MRR 财务测算器**，拒绝阅读疲劳。

## 🏛️ Mode 6: 自动化商业情报作战室

当运行在 **Mode 6** 时，委员会将自主执行工业级情报扫描与产品原型构建：

```
 1. 真实数据地毯式扫描  ──>  2. 委员会多角对抗辩论  ──>  3. 福克纳创新工具极限施压  ──>  4. 交互式 HTML5 作战室
 (谷歌地图/SEC/Reddit)       (蒂尔 / 丁元英 / 塔勒布)    (SCAMPER / KT 决策矩阵)        (5分钟语音简报 + 原型)
```

* ⚡ **实时产品交互原型**：网页内直接体验核心功能，验证价值主张。
* 📊 **动态 \$10k/月 MRR 财务测算器**：拖动滑块实时计算单客成本、毛利率与现金流。
* 🚀 **零广告获客冷启动工具包**：现成可复制的 B2B 私信话术与合作协议模板。

## 📦 安装与配置

### Antigravity & Codex
直接添加到你的项目或全局技能目录：

```bash
mkdir -p .agents/skills/genius-council
curl -sSL https://raw.githubusercontent.com/tianchengc/genius-council/main/SKILL.md > .agents/skills/genius-council/SKILL.md
```

### Claude Code
```bash
/plugin marketplace add genius-council
/plugin install genius-council@genius-council
```

### Cursor & Windsurf
将 `SKILL.md` 的内容粘贴至 `.cursorrules` 或系统提示词中。
